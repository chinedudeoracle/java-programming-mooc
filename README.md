# Java Programming MOOC

Java programming exercises and projects from the **University of Helsinki Java Programming MOOC**.

This repository documents my progress through the course, including programming exercises, practice projects, and other coursework.

## Course

**University of Helsinki – Java Programming MOOC**

The course focuses on developing practical Java programming skills through hands-on exercises and progressively more complex programming problems.

## Repository Structure

The exercises are organized according to the structure provided by the MOOC:

```text
java-programming-mooc/
│
├── part01-Part01_01.Sandbox/
├── part01-Part01_02.AdaLovelace/
├── part01-Part01_03.OnceUponATime/
├── part01-Part01_04.Dinosaur/
├── part01-Part01_05.Message/
├── ...
│
└── part01-Part01_37.GiftTax/
````

Each exercise is maintained as its own Maven project and contains the Java source code and the accompanying tests provided by the course.
